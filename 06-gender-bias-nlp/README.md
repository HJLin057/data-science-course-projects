# Stereotype Classification on LLM-Generated Dutch Sentences

Part of a group project that reproduced a 2025 master's thesis on gender bias in Dutch text generation.
This folder contains **my part only**: the classification experiment and an extra pre-training experiment.

## Data

3,965 Dutch sentences generated by LLaMA 3, each pairing a gendered noun with an adjective. A sentence is
labelled *stereotypical* when the noun and the adjective have the same gender and *anti-stereotypical* otherwise.
Split 70 / 15 / 15 into train, validation and test, stratified by label.

## Experiments

1. **Fine-tuning:** multilingual DistilBERT is fine-tuned for 3 epochs with two hyperparameter sets taken from
   the thesis' search ranges. The set with the better validation F1 is kept.
2. **Extra pre-training:** DistilBERT's masked-language-model pre-training is continued for 3 epochs on 2,751
   sentences in which gendered words are replaced by a neutral `[PERSON]` token. It is then fine-tuned in exactly
   the same way.

## Results

| Model | Test F1 |
|---|---|
| Fine-tuned, set A (learning rate 2e-5, batch 16, weight decay 0.01) | 0.778 |
| Fine-tuned, set B (learning rate 4e-5, batch 32, weight decay 0.0001) | 0.762 |
| Extra pre-training on the neutral corpus, then set A | **0.806** |

The test F1 rose from 0.778 to 0.806 after the extra pre-training. The neutral corpus was made from the
training sentences rather than an independent corpus, and each setting was run once, so the gain should be
read with care.
